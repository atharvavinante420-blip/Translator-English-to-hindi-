# English to Hindi Translator

A simple **English-to-Hindi Translator** built using **HTML, CSS, and JavaScript**.

This project uses the **MyMemory Translation API** to translate English text into Hindi. It was created as a beginner JavaScript project to understand API integration, asynchronous programming, DOM manipulation, and handling API responses.

## Features

- Translate English text into Hindi
- Simple and clean user interface
- Uses JavaScript Fetch API
- Uses `async/await`
- Handles empty input
- Supports longer text using text chunking
- Uses `encodeURIComponent()` for URL encoding
- Handles API errors using `try...catch`
- Displays the translated text directly on the webpage

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- MyMemory Translation API
